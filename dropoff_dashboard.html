Methodology. Total Leads = COUNTUNIQUE of phone numbers; Unique Attempts = non-blank call-time entries; Connected = Connect Status starting "Connected"; Meaningful Connect = Connect Status exactly "Connected – spoke to customer"; Interested = Interest Bucket in either "Interested – Not Yet" state; Booked = booking flag = 1 on a connected call. Reason and outcome tables group each logged primary-reason code under its mapped outcome bucket (Wouldn't / Not Yet / Couldn't / Existing Wiom / Already Booked / Unknown), identical to the mapping used in the source sheet's DAILY SUMMARY tab. All text matching is case-insensitive, matching Google Sheets' COUNTIF/COUNTIFS behaviour — several fields (Connect Status, Interest Bucket) carry mixed-case duplicates in the raw data that are folded together here exactly as they are on the live sheet.
